# gentk

Generator Toolkit

Кроссплатформенный консольный инструмент для генерации:

- паролей;
- UUID;
- ULID;
- идентификаторов CUID2;
- Nano ID;
- TSID.

Написан на Rust.

---

## Возможности

### Генерация паролей

- криптографически стойкий источник случайности (через ОС);
- настраиваемая длина;
- строчные буквы;
- заглавные буквы;
- цифры;
- безопасные специальные символы;
- дополнительные специальные символы (для продвинутого использования);
- ограничение последовательных повторов (0–3, 0 = без ограничений);
- ограничение общего количества вхождений символа (0–3, 0 = без ограничений);
- исключение неоднозначных символов;
- стратегия удовлетворения ограничений (retry/slide/error);
- поддержка конфигурации в JSON.

---

### Генерация UUID

Поддерживаемые версии:

- UUID4
- UUID5
- UUID7

UUID5 требует указания пространства имён и имени; значения по умолчанию могут храниться в конфигурации.

---

### Дополнительные идентификаторы

Поддерживаемые генераторы:

- ULID
- CUID2
- Nano ID (настраиваемая длина и алфавит)
- TSID

Snowflake-идентификаторы намеренно не поддерживаются.

## Быстрый старт

Генерация одного пароля (по умолчанию):

```bash
gentk
```

Десять паролей:

```bash
gentk 10
```

Двадцать паролей длиной 32:

```bash
gentk --length=32 20
```

---

## Параметры пароля

Длина (8–65535, по умолчанию 13):

```bash
--length=32
```

Группы символов:

- `--lower=true|false` (по умолчанию true) – строчные буквы a‑z
- `--upper=true|false` (по умолчанию true) – заглавные буквы A‑Z
- `--digits=true|false` (по умолчанию false) – цифры 0‑9
- `--special=true|false` (по умолчанию false) – безопасные спецсимволы `@#%-_=+:,./`
- `--extra=true|false` (по умолчанию false) – дополнительные спецсимволы `!$^&*()[]{}|;'"\`<>?~`

Ограничение повторов (0–3, 0 = без ограничений):

```bash
--repeat=2
```

Ограничение повторного использования (0–3, 0 = без ограничений):

```bash
--reuse=3
```

Стратегия обработки ограничений:

```bash
--strategy=retry   # retry (по умолчанию), slide, error
```

Исключение неоднозначных символов (0Oo1lI5S8B):

```bash
--exclude-ambiguous=true
```

Вывод в JSON (одно значение → `{"value":"..."}`, несколько → `{"values":["..."]}`):

```bash
--json
```

Генерация десяти паролей со всеми группами, включая дополнительные символы:

```bash
gentk --lower=true --upper=true --digits=true --special=true --extra=true 10
```

## UUID5

Требует пространство имён и имя. Могут быть заданы через CLI или конфигурационный файл (по умолчанию пространство имён `dns`, имя `example.com`, если конфиг существует).

```bash
gentk uuid5 --namespace=dns --name=example.com
gentk uuid5 --namespace=url --name=myapp 50
```

Поддерживаемые пространства имён: `dns`, `url`, `oid`, `x500` или UUID-строка.

## Nano ID

Длина по умолчанию 21, алфавит по умолчанию (62 символа).

```bash
gentk nanoid
```

Настраиваемая длина:

```bash
gentk nanoid --length=32
```

Настраиваемый алфавит (минимум 2 символа):

```bash
gentk nanoid --alphabet=abcdef123456
```

Генерация пятидесяти идентификаторов:

```bash
gentk nanoid 50
```

Добавьте `--json` к любой команде. Для одного значения: `{"value":"..."}`, для нескольких: `{"values":["...", ...]}`. Без пустых строк.

## Конфигурация

Сгенерировать конфигурационный файл по умолчанию (записывает `gentk.json` в текущий каталог):

```bash
gentk config
```

Пример содержимого:

```json
{
  "password": {
    "length": 13,
    "lower": true,
    "upper": true,
    "digits": false,
    "special": false,
    "extra": false,
    "repeat": 0,
    "reuse": 0,
    "exclude_ambiguous": false,
    "strategy": "retry"
  },
  "uuid5": {
    "namespace": "dns",
    "name": "example.com"
  },
  "nanoid": {
    "length": 21,
    "alphabet": null
  },
  ...
}
```

## Порядок поиска конфигурации

1. Встроенные значения по умолчанию
2. `./gentk.json`
3. `$XDG_CONFIG_HOME/gentk/config.json` (или `~/.config/gentk/config.json`)
4. `%APPDATA%\gentk\config.json` (Windows)
5. `/etc/gentk/config.json`
6. Аргументы командной строки (наивысший приоритет)


Все страницы справки показывают допустимые диапазоны (например, `--repeat <0-3>`, `--length <8-65535>`).

## Версия

```bash
gentk --version
```

Версия автоматически формируется из истории сборок. Release-сборки получают полную семантическую версию, debug-сборки добавляют суффикс `-dev`.
