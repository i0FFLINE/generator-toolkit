# Техническое задание

Проект: gentk

Полное название: Generator Toolkit

Язык реализации: Rust

Минимальные требования:

- стабильный Rust;
- отсутствие unsafe-кода;
- кроссплатформенность;
- строгая типизация;
- английский язык интерфейса.

---

# Назначение

gentk представляет собой консольный набор генераторов для:

- паролей;
- UUID (v4, v5, v7);
- ULID;
- CUID2;
- Nano ID;
- TSID;
- конфигурационного файла.

Программа должна быть предсказуемой, строго типизированной и легко расширяемой.

# Генерация паролей

По умолчанию программа работает в режиме паролей. Позиционный аргумент — количество (по умолчанию 1).

Параметры:

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `--length` | u16 (8..=65535) | 13 | Длина пароля |
| `--lower` | bool | true | Строчные буквы a-z |
| `--upper` | bool | true | Заглавные буквы A-Z |
| `--digits` | bool | false | Цифры 0-9 |
| `--special` | bool | false | Безопасные спецсимволы `@#%-_=+:,./` |
| `--extra` | bool | false | Дополнительные спецсимволы `!$^&*()[]{}¦;'"\`<>?~` |
| `--repeat` | u8 (0..=3) | 0 | Максимум повторов подряд (0=нет) |
| `--reuse` | u8 (0..=3) | 0 | Максимум вхождений символа (0=нет) |
| `--exclude-ambiguous` | bool | false | Исключить `0Oo1lI5S8B` |
| `--strategy` | строка | "retry" | Стратегия: retry, slide, error |

Булевы значения принимают только `true` или `false`.

---

# Наборы символов

- Строчные: `a-z`
- Заглавные: `A-Z`
- Цифры: `0-9`
- Безопасные спецсимволы: `@#%-_=+:,./`
- Дополнительные спецсимволы: `!$^&*()[]{}|;'"\`<>?~`

Формируются динамически по флагам. Если ни одна группа не включена — ошибка.

---

# Ограничения

## repeat
Максимум последовательных одинаковых символов. 0 — без ограничений.

## reuse
Максимум вхождений одного символа. 0 — без ограничений.

## Стратегия
- `retry` — повторная генерация (до 1000 попыток).
- `slide` — исправление на лету (недетерминированно).
- `error` — немедленная ошибка при невыполнении.

Невыполнимые ограничения (например, `--length=8 --reuse=1 --lower=true`) — ошибка валидации.
Если `repeat > length` или `reuse > length`, выводится предупреждение через `Notice::warn`.

# Источник случайности

Используется крейт `getrandom` — прямой доступ к криптографически стойкому генератору ОС. Реализован легковесный `OsRng` в `src/random/os_rng.rs` с методами `gen_range` и `choose`. Крейт `rand` не используется.

---

# Команды UUID

- `uuid4` — случайный UUID v4.
- `uuid5` — UUID v5 на основе пространства имён и имени. По умолчанию из конфига: `namespace="dns"`, `name="example.com"`. Поддерживаемые пространства: `dns`, `url`, `oid`, `x500`, UUID-строка.
- `uuid7` — временной UUID v7.

---

# ULID, CUID2, TSID

Простые генераторы, использующие соответствующие крейты. Без настраиваемых параметров, только количество.

---

# Nano ID

Параметры:
- `--length` (по умолчанию 21) — длина.
- `--alphabet` (по умолчанию 62 символа) — алфавит, минимум 2 символа.

---

# JSON-вывод

Глобальный флаг `--json`. Одно значение: `{"value":"..."}`, несколько: `{"values":["...","..."]}`.

---

# Конфигурация

Команда `gentk config` без аргументов создаёт `gentk.json` со значениями по умолчанию для всех секций, включая конкретные значения для `uuid5` и `nanoid`.

Приоритет:
1. Встроенные значения
2. `./gentk.json`
3. `~/.config/gentk/config.json`
4. `/etc/gentk/config.json`
5. Аргументы командной строки (наивысший)

---

# Вывод

Обычный текст: каждое значение с новой строки, пустые строки перед первым и после последнего.
JSON: объект, как описано.

---

# Уведомления

`Notice::warn` — предупреждения в stderr.
`Notice::show` — запрос подтверждения с вариантом `[y/N]`.

---

# Обработка ошибок

Единый enum `AppError` (использует `thiserror`):
- `CliError`
- `ConfigError`
- `ValidationError`
- `GeneratorError`
- `IoError`
- `SerializationError`
- `NoticeAborted`

---

# Версионирование

Автоматическое через `build.rs` и `src/version_history.json`. При release-сборке вычисляется хеш `Cargo.lock`, при изменении — увеличивается минорная версия, иначе — патч. Debug-сборки добавляют `-dev`. Версия выводится по `--version`.

# Структура проекта (фактическая)

```text
src/
    main.rs
    cli/
    commands/
        password.rs, config.rs, uuid4.rs, uuid5.rs, uuid7.rs,
        ulid.rs, cuid2.rs, nanoid.rs, tsid.rs
    config/
    errors/
    output/
    random/
```

Генераторы встроены в файлы команд (без отдельной папки `generators/`).
